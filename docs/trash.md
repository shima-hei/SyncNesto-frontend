# 削除データの復元

`/projects/joined/{projectId}/trash` にProject内のごみ箱を追加する。名前・種類の絞り込み、20件ページング、削除日時・保持期限・復元不可理由を表示する。標準ロールでは文書を更新できる利用者にナビゲーションを表示し、一覧・復元はBackendの資源別RBACで判定する。

対象は要件定義書、セクション、要件、タスク、テスト設計書、ドキュメント、文書添付。通常の復元期限は削除から30日。親を戻しても個別削除された子は戻さない。親が削除済みなら親を先に復元する。期限切れの行は回収処理まで残り、復元はできない。

復元確認後に削除日時・版を送る。競合・権限変更・回収済みなら操作を閉じ、一覧を再取得する。成功後は詳細・一覧・横断検索を無効化し、「復元したデータを開く」リンクを表示する。Query keyは組織・Projectを含み、検索・一覧を永続化しない。本文・添付URLはごみ箱APIから取得しない。

削除確認は今回の対象のみ復元できる説明に変える。ユーザー・Project・ボード・単独コメント等は対象外。デモではログアウト・セッション期限切れで削除済みデータも全破棄される。

APIと回収コマンドはBackendの `docs/frontend-trash-api.md` を参照する。UIの完全削除やクラウドの自動スケジュール設定は行わない。
