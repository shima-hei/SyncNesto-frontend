# ドキュメント管理

参加プロジェクト配下の`/documents`で作業ガイドや議事録を管理する。
一覧のタイトル・本文検索、Markdownの作成・編集とプレビュー、添付、業務への関連付け、版履歴を提供する。

ページはServer Componentとし、フォームとQueryをfeature内のClient Componentへ分ける。
APIはBackend OpenAPIからOrvalで生成し、既存BFF・Cookie・CSRF・組織選択を使用する。
権限表示は既存role key。Backend permissionを最終判断とする。

編集はversionを送信する。409では項目ごとに自分の入力と最新値を比較し、
未編集の項目には他の更新を保持したうえで、明示的な再更新を行う。
下書きは既存useFormDraftを利用する。通常利用はユーザー・組織別に保持し、
デモ利用では既存メモリ領域だけに保存し、終了時に破棄する。

添付は既存uploadWithPlanでサーバー送信・presigned直接送信の両方に対応する。
許可拡張子からMIMEを正規化し、確定前の内容検証と容量判断はBackendが行う。
添付の本文内表示は行わず、取得操作で短期URLを発行する。

要件へのリンクは所属する要件定義書を経由する。候補は50件、登録済み関連も50件まで。
閲覧できない・削除された関連先にはリンクを出さない。
版一覧は最新100版。版番号指定で古い版も確認できる。
版の対象はタイトル・本文のみ。添付と関連は現在の内容。

Backend契約は`docs/frontend-documents-api.md`を参照する。
横断検索、ごみ箱での文書・添付の復元、通常データの保持期限（標準30日）に対応する。監査ログの閲覧UIは後続課題。
