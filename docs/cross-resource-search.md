# 横断検索

サイドバーの「横断検索」(`/search`) から、参加プロジェクトの要件定義書・要件・タスク・
テスト設計書・項目・ケース・ドキュメントをまとめて検索する。

- 名前・コード・本文の部分一致。本文の一致付近を短く表示し、一致語を強調する。
- 種類と参加プロジェクトで絞り込める。案件候補も名前・コードによる検索とページ切り替えを備える。
- 種類の選択肢には、閲覧可能な一致件数を表示する。
- 1ページ20件。条件とページをURLへ保持し、ブラウザの戻る・進むで同じ検索へ戻れる。
- 結果から既存の詳細へ移動する。項目のUUID、ケースのUUID、要件の親定義書IDを維持する。
- 狭い画面ではProject情報を結果本文にまとめ、横スクロールを必要としない。
- 読込・空・エラー・再試行を既存の共通部品で表示する。

Backendの `/search`・`/search/projects` が現在の組織、Project所属、Project閲覧と種類別閲覧権限を判定する。
Frontendの役割表示で代用しない。件数と候補名にも同じ境界を適用する。
API clientはOpenAPIからOrval生成。通信のAbortSignalを渡し、変更前の検索結果を次の条件へ流用しない。
検索結果はReactの文字列として描画し、Markdown・HTMLを実行しない。
履歴・コメント・添付本文・拡張列・因子や水準は対象外。検索語の履歴・下書き保存は追加しない。

文書管理PRに続く変更で、Backendの新APIを先に反映する。検索機能自体のDB migrationは不要。
